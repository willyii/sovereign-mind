# 推演笔记归档与复盘 (Journal Archive)

所有笔记统一存放在：`/Users/xinlongyi/Documents/SovereignMindNotes/`（以下简称“笔记库”）。

## 玩法一：保存本次推演（当用户说“存下来”、“记一下”）

1. **生成文件名**：格式为 `YYYY-MM-DD-<简短主题>.md`（例如 `2026-11-16-AI一人公司推演.md`）。如果同一天有重名，在后面加 `-2`、`-3`。
2. **用大白话整理成固定模板**：
   ```markdown
   # <简短主题>

   - **日期**：YYYY-MM-DD
   - **训练模式**：前提假设推演 / 历史拐点盲测 / 观点挑刺
   - **关键词**：#标签1 #标签2

   ## 1. 当时定下的前提假设
   > 用 1～3 句话写清我们假定了什么。

   ## 2. 你的核心推演
   - 第一步判断：...
   - 连锁反应：...

   ## 3. 发现的漏洞与修正
   - 当时忽略了什么 / 对手会怎么反击：...
   - 修正后的判断：...

   ## 4. 顺便聊到的历史背景（如有）
   - ...

   ## 5. 带走的一条规律
   **一句话总结**：...
   ```
3. **更新总目录 `INDEX.md`**：在 `/Users/xinlongyi/Documents/SovereignMindNotes/INDEX.md` 的表格里追加一行记录（日期、主题、文件链接、带走的一句话规律）。
4. **确认反馈**：把保存好的文件链接发给用户，并用 1 句话概括这次沉淀下来的核心规律。

## 玩法二：复盘与总结（当用户说“复盘”、“总结最近的笔记”）

1. 先读取 `/Users/xinlongyi/Documents/SovereignMindNotes/INDEX.md`，再按需要读取最近的几篇笔记文件。
2. 用简单直白的话帮用户做一份“思考体检报告”：
   - **练了哪些主题**：梳理最近覆盖的领域和历史时代。
   - **最常踩的思考坑**：点出重复出现的盲区（比如是不是经常低估资金转移速度、或者容易忘了既得利益者的反击）。
   - **已经攒下的规律库**：把分散在各篇里的“一句话规律”串起来，看看哪些规律可以互相印证。
3. 最后给 1 个具体的**下次训练建议**（针对最薄弱的环节出题）。
