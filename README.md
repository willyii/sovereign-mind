# Sovereign Mind (`sovereign-mind`)

An Antigravity plugin for training first-principles **megapolitical deduction**, **historical pattern synthesis**, and **extreme-scenario stress testing**, inspired by the analytical style of William Rees-Mogg and James Dale Davidson (*The Sovereign Individual*, *Blood in the Streets*).

Instead of giving passive summaries, this plugin turns your Antigravity agent into a **Socratic sparring partner** that challenges hidden assumptions, maps actor incentives, tests second- and third-order consequences, and audits historical analogies for boundary-condition failures.

## What's Included

- **`deductive-drill`** (`skills/deductive-drill/SKILL.md`): Interactive multi-turn Socratic drills on extreme technological, monetary, and geopolitical shocks.
- **`historical-parallel`** (`skills/historical-parallel/SKILL.md`): Blind-spot historical simulations and structural analogy stress-testing (with a curated inflection-point catalog).
- **`thesis-stress-test`** (`skills/thesis-stress-test/SKILL.md`): Adversarial red-teaming of any macro, tech, or investment thesis—steelmanning, incentive mapping, tail-risk checks, and falsifier definition.
- **`rules/AGENTS.md`**: Lightweight activation posture when discussing logic training, extreme scenarios, or Rees-Mogg-style deduction.

## Local Installation (Antigravity)

Symlink (or copy) this repository into `~/.gemini/config/plugins/sovereign-mind`:

```bash
ln -s /Users/xinlongyi/Documents/Github/sovereign-mind ~/.gemini/config/plugins/sovereign-mind
```

Or install from another machine after cloning:

```bash
git clone https://github.com/<your-username>/sovereign-mind.git ~/.gemini/config/plugins/sovereign-mind
```

Antigravity discovers it automatically. You can enable, disable, or inspect it in Antigravity's **Customizations / Plugins** page.
